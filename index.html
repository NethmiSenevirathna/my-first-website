Welcome to My Website

Welcome to my cloud computing learning portfolio. This website documents my learning about cloud technology, web development and career opportunities in cloud computing and cybersecurity.

What Is Cloud Computing?

Cloud computing provides computing services such as servers, storage, databases, networking and software over the internet. It allows users and organisations to access resources without managing all the physical infrastructure themselves.

My Learning Activity

I created this website using HTML and CSS, stored my files in a GitHub repository and published the website using GitHub Pages. This activity demonstrates how online platforms can make digital content accessible from different locations.

GitHub Pages hosts this static website. It is not the same as deploying a complete cloud application on a platform such as AWS or Microsoft Azure.
