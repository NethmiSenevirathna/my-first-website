Introduction

Cloud computing has transformed the healthcare sector by allowing hospitals, clinics and healthcare professionals to store, manage and access information through internet-based services. Instead of relying entirely on local computers and physical servers, healthcare organisations can use cloud platforms to support electronic health records, telemedicine, medical collaboration and data analysis.

Benefits of Cloud Computing in Healthcare

One major benefit is accessibility. Authorised healthcare professionals can access patient information from different locations, which can support faster decisions and better coordination between medical teams. Cloud-based telemedicine also enables patients to consult healthcare professionals remotely. In addition, cloud infrastructure can provide flexible storage and computing resources as an organisation grows.

Cloud computing can also support research by helping authorised teams analyse large amounts of medical data. However, these benefits depend on reliable internet connectivity, suitable system design and responsible data management.

Security Challenges

Healthcare data is highly sensitive, making security a major concern. Unauthorised access, ransomware, data breaches and misconfigured cloud services can expose confidential patient information. Healthcare organisations must use appropriate access controls, encryption, secure backups, monitoring and incident response procedures. They must also comply with applicable privacy and healthcare regulations. Moving data to the cloud does not automatically make it secure.

Reflection on My GitHub Pages Activity

Creating this website helped me understand cloud-based publishing in a practical way. I created an HTML file, stored it in a GitHub repository and used GitHub Pages to publish the content online. I can now access the website through a web address rather than keeping the page only on my computer. This activity helped me connect theoretical cloud computing concepts with a real digital workflow.

However, I also learned that GitHub Pages is a static website hosting service, not a complete healthcare cloud system. It would not be appropriate to store real patient records in this public learning project. This distinction helped me understand why cloud services must be selected according to their purpose and security requirements.

Conclusion

Overall, cloud computing can improve healthcare accessibility, collaboration and scalability, but these advantages must be balanced with strong security and privacy protections. As a Cyber Security and Forensic Computing student, I want to develop my understanding of cloud security, identity management and data protection so I can help organisations use cloud technologies responsibly.
