1. Understanding the Four Cloud Models

SaaS — Software as a Service

SaaS provides ready-to-use software through the internet. Examples include Microsoft 365 and Salesforce. Users access the software without managing its underlying infrastructure.

PaaS — Platform as a Service

PaaS provides a platform for developers to build, test and deploy applications without managing every underlying server. Examples include Azure App Service and Google App Engine.

IaaS — Infrastructure as a Service

IaaS provides computing resources such as virtual machines, networking and storage. Examples include Amazon EC2 and Azure Virtual Machines.

SECaaS — Security as a Service

SECaaS provides security capabilities through cloud-based services, such as security monitoring, email protection, identity management and threat detection.

3. Requirements and Main Responsibilities

SaaS: Application Support Analyst

Requirements: Basic IT knowledge, communication, troubleshooting, ticketing systems and an understanding of software applications.

Responsibilities: Help users solve software problems, investigate errors, document incidents, test fixes and escalate complex issues.

Useful skills: SQL basics, Excel, customer service and clear technical documentation.

PaaS: Junior Cloud / Platform Support Engineer

Requirements: Basic programming, networking, Linux fundamentals and familiarity with one cloud platform.

Responsibilities: Assist with application deployments, troubleshoot platform issues, monitor services and support developers.

Useful skills: Python, Git, command-line tools and introductory Azure or AWS knowledge.

IaaS: Cloud Support Associate

Requirements: Understanding of operating systems, IP networking, virtual machines, storage and basic cloud concepts.

Responsibilities: Troubleshoot cloud infrastructure, investigate connectivity problems, monitor resources and help manage access and backups.

Useful skills: Linux, Windows Server, TCP/IP, DNS and introductory AWS or Azure training.

SECaaS: Junior SOC Analyst

Requirements: Cybersecurity fundamentals, networking, operating system logs, attention to detail and incident documentation skills.

Responsibilities: Monitor security alerts, investigate suspicious activity, analyse logs, record incidents and escalate threats to senior analysts.

Useful skills: SIEM tools such as Microsoft Sentinel or Splunk, basic threat analysis and security awareness.
